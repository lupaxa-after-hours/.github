<h1 align="center">Lupaxa After Hours</h1>

**Lupaxa After Hours** contains the projects that happen when the serious work is finished and someone says, "I wonder if we could..."

This is a home for Friday-afternoon coding, spontaneous experiments, questionable
ideas, unnecessary tools, tiny utilities, prototypes, proofs of concept, and
anything else we decide to build simply because it sounds interesting or amusing.

Projects here don't need a roadmap, a business case, or even a particularly good
reason to exist. Some might eventually become useful and graduate into another
part of The Lupaxa Project. Others might remain permanently unfinished,
spectacularly over-engineered, or serve no purpose beyond teaching us something
and keeping us entertained for an afternoon.

Expect experiments with unfamiliar technologies, solutions to problems nobody
actually has, reinventions of things that already work perfectly well, and the
occasional project that somehow becomes far more serious than originally intended.

The rules are simple:

- Build things because they seem interesting.
- Try technologies we haven't used before.
- Don't worry if an idea is slightly ridiculous.
- Learning something counts as success.
- Having fun counts too.
- Production can wait until Monday.

**No roadmap. No promises. No sensible Friday deployments.**
